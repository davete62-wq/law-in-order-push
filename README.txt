IMPORTANT SECURITY LIMITATION
This is a front-end prototype. It stores data in the browser's localStorage.
That means:
- Access codes are visible to anyone who inspects the source code.
- Changes are saved only in the browser/device where they were made.
- Group chat messages are not shared live between different users/devices.
- This is NOT suitable for real private student records or confidential cases.

Before real club use, connect a backend such as Supabase or Firebase:
- Store users and hashed credentials securely.
- Enforce president/vice-president permissions on the server/database.
- Store cases, events, rankings, teams, announcements and chat messages centrally.
- Use database access policies so delegates cannot access leadership settings.
- Add secure file uploads for case documents.
- Never rely on hiding buttons in the browser as security.
